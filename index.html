Co-Med: a healthcare system for a Doctor's Office

Full Stack Development

Co-Med is a full-stack web application for managing medical office operations, built on the MERN stack (MongoDB, Express.js, React, Node.js). The platform covers the core workflows of a medical practice: patient registration and management, appointment scheduling, clinical history tracking, and prescription generation. The frontend is built with React and delivers a responsive, single-page experience, while the backend exposes a RESTful API with Node.js and Express, persisting data in MongoDB. The project was developed end-to-end as a personal initiative, covering architecture decisions, data modeling, and full-stack implementation.

PomodoRock: PWA built with React for focus and productivity.

PWA | Web Development | Productivity

PomodoRock is a Progressive Web App built with React, Redux, and Firebase, designed around the Pomodoro Technique to help users manage their focus and productivity. The app allows users to break work into timed sessions, assign custom labels to each session, and receive browser notifications when a session ends. It includes a statistics dashboard powered by Chart.js that visualizes productivity patterns — time spent per label and most productive days of the week. Users can sign in to sync their data across devices via Firebase, and the app works fully offline thanks to its PWA architecture. The UI is built with Material UI and styled-components, with dark mode support and installability across any PWA-compatible browser.

React.js | Redux | Firebase | CSS3 | SCSS
